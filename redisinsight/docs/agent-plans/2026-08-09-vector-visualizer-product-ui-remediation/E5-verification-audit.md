# E5 — Verification and audit

Run with fresh contexts after implementation completes:

1. [E5.VERIFY](tasks/E5-VERIFY.md) — independent execution proof and reference comparison.
2. [E5.AUDIT](tasks/E5-AUDIT.md) — fresh read-only audit of requirements, source, tests, screenshots, and proof boundaries.

If the Verifier is NOT READY, delegate bounded repairs by exact finding and rerun verification. If the Auditor is NOT APPROVED, do the same and require a new fresh audit. Historical technical audits do not substitute for either task.
